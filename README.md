# Spring Boot 3 User Authentication REST API

## Overview

This project is a RESTful User Authentication API built using Java 17 and Spring Boot 3.

It demonstrates a layered architecture with Controller, Service, Repository, DTO, and Entity.

---

## Technologies

- Java 17
- Spring Boot 3
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
- Jakarta Validation
- BCrypt Password Encryption
- Postman

---

## Features

- User Registration
- User Login
- User Logout
- Get User by ID
- Get All Users
- Update User
- Delete User
- Global Exception Handling
- Request Validation
- Password Encryption

---

## API Endpoints

POST /api/v1/users/signup

POST /api/v1/users/login

POST /api/v1/users/logout

GET /api/v1/users

GET /api/v1/users/{id}

PUT /api/v1/users/{id}

DELETE /api/v1/users/{id}
